# Plasma

Fabric-мод для Minecraft **26.2**, который открывает **локальный** мост и позволяет выполнять произвольный Java-код внутри игры — с подтверждением через чат, компиляцией сниппетов на лету и локализацией (английский / русский / испанский).

> **Внимание:** это удалённое выполнение кода. Используйте мод только на своей машине и в своих мирах. Не ставьте его на основной аккаунт и не заходите с ним на серверы.

## Возможности

- **Локальный TCP-мост** — случайный порт (30000–50000), защита токеном.
- **Подтверждение через чат** — каждый запрос показывается в чате; вы разрешаете/отклоняете его командами.
- **Выполнение сниппетов** — отправьте произвольный Java-код (`{"code": "..."}`), он компилируется и исполняется на лету.
- **Выполнение классов** — запуск любого класса с `Runnable` или методом `main`.
- **Мультипакетные payload** — массив пакетов с `packetid` / `maxpacketid`.
- **Клиентские эффекты** — стирание чанков, призрачные предметы/сущности, дождь из ТНТ, взрывы, запуск игрока.
- **Действия во встроенном сервере** — в одиночной игре можно, например, выдать предметы в настоящий инвентарь.
- **Локализованный чат** — английский, русский, испанский через встроенные переводы Minecraft.

## Сборка

Требования:

- **JDK 25+** (моду нужен `java >= 25`).
- Интернет при первой сборке (Gradle скачает зависимости); дальше работает `--offline`.

```bash
./gradlew build            # обычная сборка
./gradlew build --offline  # если зависимости уже скачаны
```

В Windows используйте `gradlew.bat` вместо `./gradlew`.

Готовый jar появится в `build/libs/bm3-plasma-1.0.0.jar`. Готовый jar также лежит в `release/` (с SHA-256 суммой), если не хотите собирать сами.

## Установка

1. Скопируйте `build/libs/bm3-plasma-1.0.0.jar` (или из `release/`) в папку `mods/` экземпляра **Fabric 26.2** (нужен Fabric API). Пользователи Legacy Launcher / vanilla: кладите в `.minecraft/mods` и запускайте профиль **Fabric**.
2. Запустите игру. В чате появится предупреждение. Мост остаётся **закрытым**, пока вы не введёте `/plasma agree` — команда покажет открытый порт.
3. Отправляйте payload с той же машины (только localhost) через `scripts/send_payload.py` или помощники из `examples/`.

## Управление — команды в чате

| Команда | Действие |
|---|---|
| `/plasma agree` | Принять условия и открыть мост |
| `/plasma allow` | Разрешить текущий запрос |
| `/plasma allow always` | Доверять IP — исполнять всё от него автоматически |
| `/plasma deny` | Отклонить текущий запрос |
| `/plasma deny always` | Заблокировать IP навсегда |
| `/plasma trust` | Довериться IP текущего запроса |
| `/plasma betray` | Отозвать доверие (и снять блокировку) |
| `/plasma confirm` | Подтвердить отложенное действие |
| `/plasma close` | Закрыть мост (требует подтверждения) |
| `/plasma forcekill` | Мгновенно закрыть мост и отклонить все запросы |
| `/plasma echo false` | Замолчать чат Plasma до `/plasma echo true` (вывод payload всё равно виден) |
| `/plasma echo true` | Вернуть полный вывод |

## Примеры

Готовые payload лежат в `examples/`. Отправьте один (порт из сообщения `/plasma agree`):

**macOS / Linux:**
```bash
cd examples
chmod +x send.sh
./send.sh 46946 01_hello.json
```

**Windows (PowerShell):**
```powershell
cd examples
.\send.ps1 -Port 46946 -Payload .\01_hello.json
```

Токен-конфиг ищется автоматически: PrismLauncher, `.minecraft` (Legacy Launcher / vanilla) или MultiMC; в крайнем случае — рекурсивный поиск по `%APPDATA%`. Можно указать вручную через `-Config <путь>` или переменную `PLASMA_CONFIG`.

| Файл | Что делает |
|---|---|
| `01_hello.json` | Приветствие с именем игрока — базовая проверка |
| `02_erase_chunk.json` | Стирает текущий чанк 16x16 до воздуха (клиентски) |
| `03_tnt_rain.json` | Каскад из 4 пакетов: дождь из ТНТ, взрыв, кольцо ТНТ, запуск |
| `04_ghost_diamonds.json` | 24 светящихся «призрачных» алмаза вокруг игрока |
| `05_give_diamonds.json` | Выдаёт 99 алмазов в настоящий инвентарь (одиночная игра) |
| `06_system_info.json` | Показывает ОС, пользователя, версию Java |
| `07_launch_player.json` | Подбрасывает игрока в воздух |

Совет: один раз выполните `/plasma allow always` + `/plasma confirm`, чтобы следующие payload исполнялись автоматически.

## Формат payload

`scripts/send_payload.py <хост> <порт> <токен> '<payload-json>'` отправляет:

```json
{"token": "ваш-токен", "payload": {"className": "bm3.plasma.SampleTask", "method": "run"}}
```

Одиночный пакет может быть **сниппетом** (`code`) или **классом** (`className`). Несколько пакетов образуют массив, каждый с необязательными `packetid` / `maxpacketid`.

## Конфигурация

`config/plasma.properties` хранит токен (генерируется случайно при первом запуске, если его нет). Всё работает только на loopback (`127.0.0.1`).
